# Aarya Web Developers website

Static HTML5, CSS3, and JavaScript website for Aarya Web Developers.

## Before publishing

1. Replace every `https://www.example.com/` reference in the HTML, `robots.txt`, and `sitemap.xml` with the live domain.
2. Open `assets/script.js` and add the official Payoneer payment-request URL to `paymentLink` when Atul provides one. No payment link is published by default.
3. Replace the founder placeholder in `about.html` with a personal image. Add the image under `assets/` and use descriptive alt text.
4. FormSubmit sends a one-time confirmation email to `kalukheatul@gmail.com` after the first live inquiry. Approve it to activate delivery. The form uses FormSubmit's default CAPTCHA and a hidden honeypot field; test with a real email before launch.
5. Review package prices, project examples, and the legal/privacy requirements for the live business.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server. The site has no build step or backend.
